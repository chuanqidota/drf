### 介绍
##### 定义与目的：
* Service 是 Kubernetes 中的一个抽象对象，它定义了一组具有相同功能的 Pods 的逻辑集合（通常通过标签选择器 Label Selector 连接）以及访问这些 Pods 的策略。
* 它的主要目的是为了解耦服务的消费者（如其他应用）与服务的提供者（Pods），提供一种稳定的服务访问方式，无论后端的 Pods 如何变化（例如增加、减少或重启）。

###### 负载均衡：
* Service 实现了负载均衡功能，可以将流入的请求均匀地分配给关联的 Pods，从而提高服务的可用性和扩展性。

###### 网络抽象：
* Service 提供了一个固定的 IP 地址和 DNS 名称，使得服务的消费者不需要直接关注后端 Pods 的 IP 地址变化，简化了服务的调用过程
