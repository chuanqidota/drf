假设你有一个名为example-statefulset的StatefulSet，它管理着5个Pod副本。当你更新StatefulSet的Pod模板（比如改变容器镜像版本）并设置partition: 3时，Kubernetes会确保至少有3个Pod保持为旧版本（基于.spec.template的旧配置），而剩下的2个Pod将根据滚动更新策略升级到新版本。
```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: example-statefulset
spec:
  serviceName: example-service
  replicas: 5                  # 副本总数
  updateStrategy:
    type: RollingUpdate        # 指定滚动更新策略
    rollingUpdate:             # 滚动更新的具体配置
      partition: 3              # 设置partition值为3，意味着前3个Pod将保持旧版本，其余将升级到新版本
  selector:
    matchLabels:
      app: example-app
  template:
    metadata:
      labels:
        app: example-app
    spec:
      containers:
      - name: example-container
        image: your-image:current-version   # 当前版本镜像
        ports:
        - containerPort: 8080

```
