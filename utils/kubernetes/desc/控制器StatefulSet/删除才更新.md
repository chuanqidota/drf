updateStrategy字段被设置为OnDelete，表明你需要手动删除Pod来触发基于最新StatefulSet配置的新Pod创建
```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: my-statefulset
spec:
  replicas: 3
  serviceName: my-service
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
        - name: my-container
          image: my-image:v1
  updateStrategy:
    type: OnDelete

```
