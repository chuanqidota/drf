##### Node Labels（节点标签）:
* 使用nodeSelector字段：在DaemonSet的定义中，可以通过nodeSelector字段指定节点必须具有的标签。例如，如果你希望DaemonSet只部署在标记为ipmi-enable=true的节点上，可以在DaemonSet YAML配置中添加如下部分
```yaml
 apiVersion: apps/v1
 kind: DaemonSet
 metadata:
   name: my-daemonset
 spec:
   selector:
     matchLabels:
       app: my-daemonset-app
   template:
     metadata:
       labels:
         app: my-daemonset-app
     spec:
       nodeSelector:                 # 节点选择器
         ipmi-enable: "true"
       containers:
       - name: my-daemon-container
         image: my-container-image
```

* 查看节点标签
```bash
kubectl get nodes --show-labels
```

* 给节点添加标签
```shell
kubectl label node <node-name> <label-key>=<label-value>
```
