##### 1. 准备工作
* 确保 Metrics Server 已安装：Metrics Server 是 Kubernetes 默认用于收集和提供 Pod 资源使用数据的核心组件。如果没有安装，你需要先部署它。
##### 2. 创建 HPA
* 基于 CPU 使用率：以下命令创建一个 HPA，针对名为 myapp-deployment 的 Deployment，目标是 CPU 平均使用率达到 50%，并且设置了最小副本数为 1，最大副本数为 10。
```shell
kubectl autoscale deployment myapp-deployment --cpu-percent=50 --min=1 --max=10
```
或者，通过 YAML 文件创建 HPA，例如 hpa.yaml
```yaml
apiVersion: autoscaling/v2beta2
kind: HorizontalPodAutoscaler
metadata:
  name: myapp-hpa
spec:
  maxReplicas: 10
  minReplicas: 1
  scaleTargetRef:
    apiVersion: apps/v1
    kind: Deployment
    name: myapp-deployment
  metrics:
  - type: Resource
    resource:
      name: cpu
      target:
        type: Utilization
        averageUtilization: 50
```
然后应用配置：
```shell
kubectl apply -f hpa.yaml
```

##### 3.查看 HPA 状态
* 使用以下命令查看 HPA 的当前状态，包括当前副本数、目标副本数以及最近的度量值：
```shell
kubectl get hpa
```
* 若要查看更详细的描述信息，包括历史扩缩容事件：
```shell
kubectl describe hpa myapp-hpa
```

##### 4. 更新 HPA 配置
* 如果需要调整 HPA 的参数，可以直接修改 YAML 文件并重新应用，或者使用 kubectl edit 命令直接编辑：
```shell
kubectl edit hpa myapp-hpa
```

##### 5. 删除 HPA
* 如果不再需要某个 HPA，可以使用以下命令删除：
```shell
kubectl delete hpa myapp-hpa
```
