#### 搭建私有仓库
* 首先，你需要有一个私有的镜像仓库，如 Harbor、Nexus 或 Docker Registry。确保私有仓库已经正确设置并可以访问

#### 创建Secret以进行身份验证
* 为了使Kubernetes能够从私有仓库拉取镜像，你需要创建一个Secret来存储仓库的认证信息（通常是用户名和密码或访问令牌）。这可以通过以下命令完成
```yaml
kubectl create secret docker-registry <secret-name> \
    --docker-server=<your-registry-server> \
    --docker-username=<your-username> \
    --docker-password=<your-password> \
    --docker-email=<your-email>
```
* `<secret-name>`：你为这个密钥指定的名称。
* `<your-registry-server>`：私有仓库的地址。
* `<your-username>`、`<your-password>`、`<your-email>`：私有仓库的认证信息


#### 在Pod或Deployment中引用Secret
* 在Pod或Deployment的定义中，你需要引用之前创建的Secret。这通常在yaml文件中的imagePullSecrets字段完成
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: my-app-pod
spec:
  containers:
  - name: my-app-container
    image: <your-private-repo>/<image-name>:<tag>
  imagePullSecrets:
  - name: <secret-name> # 这里填写你在上一步创建的Secret的名称
```

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: my-app-container
        image: <your-private-repo>/<image-name>:<tag>
      imagePullSecrets:
      - name: <secret-name>
```
#### 注意事项
* 确保Kubernetes集群内的节点可以访问到私有仓库，可能需要配置网络策略或防火墙规则。
* 如果私有仓库使用了自签名证书，可能还需要在集群节点上导入该证书，以避免SSL验证错误
