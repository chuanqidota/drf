#### storageClass yaml示例
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  # StorageClass 的名称
  name: my-nfs-storage-class
  # 可选的注解，例如设置为默认的 StorageClass
  annotations:
    storageclass.kubernetes.io/is-default-class: "true"
provisioner: example.com/nfs # 这里应替换为实际的 provisioner 名称，如kubernetes.io/nfs对于NFS
# 可选参数，传递给底层存储系统
parameters:
  # NFS 服务器地址
  server: nfs.example.com
  # 共享目录路径
  path: "/exports/data"

# reclaimPolicy 定义了 PersistentVolume 在 PVC 被删除时的行为
reclaimPolicy: Delete
# 可选的卷绑定模式，如动态绑定 (Dynamic) 或立即绑定 (Immediate)
volumeBindingMode: Immediate
```

#### PersistentVolume (PV) YAML 示例
* 以下是一个简单的 PersistentVolume (PV) YAML 示例，展示了一个使用 NFS 作为后端存储的 PV 配置：
```yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-nfs-example
spec:
  capacity:
    storage: 1Gi # PV 的容量
  accessModes:
    - ReadWriteMany # PV 的访问模式
  persistentVolumeReclaimPolicy: Retain # PV 被释放时的行为
  storageClassName: my-nfs-storage-class # 关联的 StorageClass（可选）
  nfs:
    path: /path/to/nfs/export # NFS 共享目录路径
    server: nfs-server.example.com # NFS 服务器地址
```
#### PersistentVolumeClaim (PVC) YAML 示例
* 接着是与之关联的 PersistentVolumeClaim (PVC) YAML 示例
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-nfs-example
spec:
  accessModes:
    - ReadWriteMany # PVC 请求的访问模式
  resources:
    requests:
      storage: 500Mi # PVC 请求的存储量
  storageClassName: my-nfs-storage-class # 与 PV 中指定的 StorageClass 匹配
```
#### 在其他资源中使用 PVC
* 在 Deployment、StatefulSet、Pod 等 Kubernetes 资源中，可以通过 volumeMounts 和 volumes 字段来使用 PVC。以下是在一个 Pod YAML 中使用 PVC 的示例
```yaml
apiVersion: v1
kind: Pod
metadata:
  name: pod-using-pvc
spec:
  containers:
  - name: my-container
    image: nginx:latest
    volumeMounts:
    - name: nfs-volume # 这里的名字需要与volumes部分定义的volumeName匹配
      mountPath: /mnt/nfs # 容器内挂载点
  volumes:
  - name: nfs-volume # 这里的名字需要与volumeMounts中的name匹配
    persistentVolumeClaim:
      claimName: pvc-nfs-example # PVC 的名称
```
> 在这个例子中，Pod 定义了一个容器，并通过 volumeMounts 将名为 pvc-nfs-example 的 PVC 挂载到了容器的 /mnt/nfs 目录下。这样，容器内的应用就可以访问到 PV 提供的持久化存储了
