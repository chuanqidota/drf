#### PostStart Hook
* 用途：在容器创建后立即执行，但不代表容器的主进程已经启动。此钩子不保证在主进程启动前执行完毕，因此不能用于阻塞或延迟主进程的启动。
* 应用场景：初始化操作、打开日志文件、设置网络连接等。
* 配置方式：在容器的 lifecycle 字段下定义 postStart，可以执行命令或 HTTP 请求等操作。
```yaml
   apiVersion: v1
   kind: Pod
   metadata:
     name: lifecycle-demo
   spec:
     containers:
     - name: main-container
       image: myimage
       lifecycle:
         postStart:
           exec:
             command: ["/bin/sh", "-c", "echo Hello from postStart > /usr/share/message"]
```

#### PreStop Hook
* 用途：在容器被终止之前执行，可以用来优雅地关闭应用、保存状态或执行清理工作。
* 应用场景：优雅关闭数据库连接、保存状态信息、发送终止信号给应用等。
* 配置方式：同样在容器的 lifecycle 字段下定义 preStop，执行命令或 HTTP 请求等。
```yaml
   apiVersion: v1
   kind: Pod
   metadata:
     name: lifecycle-demo
   spec:
     containers:
     - name: main-container
       image: myimage
       lifecycle:
         preStop:
           exec:
             command: ["/bin/sh", "-c", "touch /tmp/graceful_shutdown"]
```
> 注意，这些钩子不会影响 Pod 的整体状态，它们仅作用于单个容器，并且执行结果不会阻止 Pod 的生命周期继续进行。此外，钩子的执行结果不会直接暴露给 Kubernetes API，因此需要自行处理钩子执行的日志记录或状态跟踪
